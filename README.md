# Alfin Ardian Portfolio

A bilingual Indonesian and English portfolio site for freelance videographer Alfin Ardian. Includes a cinematic portfolio homepage and a formal, bright professional profile page. Built with plain HTML, CSS, and JavaScript, with no build step or dependencies.

## Preview locally

Serve the folder with a local static file server, then open its local HTTP address. Opening `index.html` directly as a `file://` page may prevent YouTube embeds from receiving the page referrer and can show Error 153. The modal also includes a direct YouTube link as a fallback.

## Deploy with GitHub Pages

1. Create a GitHub repository and upload `index.html`, `styles.css`, `script.js`, `profile.html`, `profile.css`, `profile.js`, `assets/alfin-ardian-portrait.png`, `assets/alfin-portrait-front.png`, `assets/alfin-camera-gimbal.png`, and `assets/alfin-cinema-camera.png`, and `README.md` to its root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. GitHub Pages will provide the published address in the same settings page.

The page uses YouTube thumbnail images and the supplied YouTube video links. Google Fonts are optional; local fallback fonts are included in the CSS.
